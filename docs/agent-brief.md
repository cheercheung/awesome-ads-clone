# Copy into your agent

Open this repository in a shell-capable agent, connect [EvoLink MCP](mcp-setup.md), and replace the input placeholders with your own files.

```text
Rebuild this reference ad for my product using the seven steps in docs/methodology.md.

Reference video: <file>
Product photos and what the product does: <files and one sentence>
Creator images or casting brief: <files or description>
Optional reference transcript and sound notes: <file or text>
Market, approved claims, target length, and budget: <details or unspecified>

Work under work/. Start by extracting frames locally and building a timestamped
shot list. Use my transcript or your native audio capabilities for sound. Mark
unverified speech, music, and sound cues as unknown. Use the optional Gemini
reader only if I opt in.

Keep the hook mechanic, proof beats, and edit rhythm. Replace the talent,
product, setting, script, and claims with my approved equivalents. Produce a
swap map, a target sheet for each clip, and a clip plan with an estimated budget.
Show me the plan before submitting paid jobs.

Use EvoLink MCP for current model requirements, reference uploads, quotes,
image and video generation, and task status. Show the exact quote and wait for
my approval before each paid request. Confirm the start frame for each clip,
then check the bound inputs against one another as well as the target. Generate
and check the first clip before continuing. Keep each task ID, result file, and
reported charge together. Check the original task if a response is delayed.

Check the remaining clips against their target sheets and repair by cause.
Trim and assemble the passed versions with local FFmpeg. Return the finished ad,
a private reference/rebuild comparison, and the plan with clip verdicts and spend.
Use only footage, likenesses, audio, and claims I can use for each intended output.
```
