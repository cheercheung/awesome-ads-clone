# Add or update a case

1. Record the source and attribution, where available. A case with production notes should explain what was replaced, what inputs mattered, what was delivered, and any defects that remained.
2. Add the original artifact mapping and disposition to [data/cases.json](../data/cases.json). Record cost only with its scope and date. Use null when the source lacks a number or date.
3. Keep each case ID stable. Use `finished` for a documented final, `draft` for work with unresolved production issues, or `output-only` when the source only supports showing the output.
4. Confirm which footage, audio, reference frames, likenesses, and copied text can be published. The case inventory records the published video and poster URLs. Use a playable video URL and a poster for each clip shown in the README.
5. Confirm links and anchors, playable exports, accurate durations, and counts across the README and inventory. Keep spend and production history distinct from media buying or campaign outcomes.
